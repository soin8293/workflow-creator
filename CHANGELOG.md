# Changelog

## 0.1.0-rc.3 — November 3, 2026

- Added public commands to check files, update the manifest, and build a ZIP from an explicit file list.
- Added one command for all tests, with a failure for empty test suites.
- Added CI for Windows and Ubuntu on Python 3.11 and 3.12.
- Expanded the installed check to validate the skill header and installed file hashes before running code.
- Added a fake-data workflow showing output checks, a failed result, repair, and saved-state resume.
- Added contribution and security guidance, change history, and one repo-level AI-assistance notice.
- Kept the core skill instructions and bundled Foundry 0.2.0 source unchanged.
